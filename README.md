# Мой рабочий график

Личный календарь смен с прогнозом зарплаты. Работает как сайт и как приложение на Android (PWA), офлайн, без регистрации.

## Возможности
- Календарь смен (день, ночь, выходной, отпуск): тап по выбранной дате меняет смену, «Быстрый ввод» заполняет месяц строкой вроде `1,4,5,8-9,18н`.
- Прогноз зарплаты «на руки», аванса и остатка по графику; сверка модели с расчётными листками.
- Тёмная тема, уведомления, экспорт смен в календарь (.ics).
- Резервная копия в файл и автокопия внутри браузера.
- Поделиться графиком по ссылке (зашифровано, по желанию вместе с итогом по зарплате).

## Запуск
1. Загрузите файлы в репозиторий и включите GitHub Pages: Settings → Pages → ветка `main`, папка `/ (root)`.
2. Откройте адрес сайта в Chrome на телефоне и выберите «Установить приложение» или «Добавить на главный экран».

## Данные и приватность
Всё хранится только в браузере устройства. В репозитории нет личных данных: тариф, надбавки и график вводятся в приложении (вкладка «Зарплата», «Параметры расчёта»). Регулярно скачивайте резервную копию (вкладка «Ещё»).

## Поделиться графиком (по желанию)
Нужен бесплатный аккаунт Cloudflare:
1. Workers & Pages → Create → Worker, вставьте код из `worker.js`, Deploy.
2. Создайте KV namespace и привяжите его к Worker под именем `SYNC` (Settings → Bindings), Deploy.
3. Подставьте адрес Worker в `SHARE_URL` в `app.js`.
4. В приложении: «Ещё» → «Поделиться графиком». Ссылка содержит ключ шифрования, не публикуйте её.

## Ограничения
Время смен (08:00–20:30 и 20:45–07:45) и подъём перед сменой (05:40) заданы в `app.js`; под другой график их нужно поменять в коде. Разбор расчётных листков рассчитан на конкретный формат. Прогноз приблизительный и не заменяет расчёт работодателя.
